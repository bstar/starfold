# Native focus outline

`amp-focus-rounded.png` is the original STAR/AMP Classic skin's MIT-licensed
24×24, 1x focus mask (`assets/skins/classic/1x/focus-rounded.png` in STAR/AMP).
Fixed six-pixel corners and tiled edges preserve its one-pixel contour.
FOLD uses AMP's exact selection color (theme accent, or foreground for Silver) and keeps the
stroke one physical pixel wide when the terminal is zoomed.
