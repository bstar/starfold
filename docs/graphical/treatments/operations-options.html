Shared rules for the implementation
Close hides the panel; it never cancels a copy. Conflicts replace progress with a clear decision. Completed copies offer “Show file” and focus the actual destination filename. Graphical labels use a readable sans-serif face; cell mode uses the terminal font at its normal size. Paths are secondary, not a tiny all-caps status sentence.
Palette controls here demonstrate theme roles. The eventual app implementation must use STAR/KIT’s live Omarchy palette; this standalone page does not listen to the desktop theme switcher.
Buttons inside the samples illustrate placement. State and palette controls, close/reopen, and decision previews are interactive; no files are modified.
