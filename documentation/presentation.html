Presentation and shortcuts

STAR/FOLD uses one persistent controller for graphical and cell presentations. Graphical is the default in supported Kitty terminals; other terminals use cells.

ActionDefault
Next themeF8; Alt+T alias
Previous themeShift+F8; Alt+Shift+T alias
Graphical / cellsF9

These application shortcuts work while Neovim has focus. Modal dialogs own their keys. Macs may require Fn/Globe with function keys. The Actions menu offers an Appearance submenu.

starfold
starfold --cells
starfold --graphical
starfold --ssh your-host --cells

Launch flags override the saved choice for that launch. F9 changes the live renderer and saves the preference on the presentation machine after the first new frame is shown. Cursor, tabs, unsaved edits, operations and playback remain in the controller. Fallback does not overwrite your preferred mode.

Configuration

[ui]
presentation = "graphical"

[ui.shortcuts]
next_theme = "F8/alt+t"
previous_theme = "shift+F8/alt+shift+t"
presentation = "F9"

Shortcut overrides belong to the controller's config, including the host config for SSH. An empty shortcut string disables that action's bindings. Invalid and duplicate appearance bindings are rejected with a configuration error.

Pane focus and Preview

Tab cycles Left, Preview and Right in Commander. Tab goes directly from Left to Preview; Shift+Tab goes directly from Right to Preview. Changing focus preserves the displayed preview, including an embedded editor. Navigation or a file selection updates it. F7 jumps straight into Preview; F6 returns to the browser from Neovim.

Previews in cells

Neovim returns its styled grid and cursor at the available cell dimensions, keeping your normal configuration and colors. Clean previews follow the browser; unsaved changes keep the existing save/discard/cancel protection. Video uses the local KIT player, terminal images where supported, and colored half blocks otherwise. AMP owns both native and cell controls. SSH audio stays on the presentation machine in both modes; unsupported helpers and output failures are reported.

Extension interface

// Viewport.cells is Some([columns, rows]) in a cell presentation.
// Return an optional validated CellGrid alongside older text fallbacks.
let grid = CellGrid {
    columns: 1, rows: 1,
    cells: vec![StyledCell {
        symbol: "x".into(), foreground: [205, 214, 244],
        background: [30, 30, 46], modifiers: 1,
    }],
    cursor: Some([0, 0]),
};
grid.validate()?;
presentation.cells = Some(grid);

Grid payloads are limited to 8,192 cells. Empty symbols represent wide-character continuation cells. Modifiers encode bold, italic, underline and strikethrough. Older providers can omit cells and use text pages.
