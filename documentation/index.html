Preview extension guide

A pane owned by FOLD. Content supplied by extensions.

Preview extensions are separate executables. FOLD selects a provider for the selected file, opens a supervised session, and places the returned presentation inside Preview. No shared library is loaded into FOLD.

Selected file→Provider hierarchy→Supervised helper→Preview content

Start here

  • Build an extension: a working Rust example and the wire contract.
  • File-type hierarchy: overlapping suffixes, MIME families, priorities and overrides.
  • Video: posters and requests to host media services.
  • NVIM: a real read/write editor inside Preview.

Ownership

OwnerResponsibilities
FOLDTheme resolution, pane title/border/padding, focus, placement, global shortcuts, footer, lifecycle and file identity.
ExtensionContent decoding, content controls, declared input keys, text/raster/native-surface presentation.
KITRendering primitives, terminal graphics, movie decoding, audio and SSH media transport.
AMPMedia button artwork, layout and hit testing.

Extensions have no API for the global footer. Metadata and playback details belong inside Preview.

Build and verify

CARGO_NET_GIT_FETCH_WITH_CLI=true nix develop -c cargo build --workspace --release --features terminal-graphics
CARGO_NET_GIT_FETCH_WITH_CLI=true nix develop -c cargo test --workspace --all-features

The workspace builds FOLD, PDF, video and NVIM helpers. PDF and video are selected automatically; NVIM is opt-in through configuration and requires an installed Neovim executable. This guide works offline: open this file in a browser.
