Video extension

Posters from the helper; playback through host media services.

The bundled starfold-preview-video is a concrete example of extending Preview without creating another player UI.

Video helper: poster + actions→FOLD: playback controller→KIT: decode / transport

Open: return the poster and media descriptor

let poster = starkit::media::poster(&path, Arc::new(AtomicBool::new(false)))?;
let pixels = poster.pixels.as_raw().clone();
let presentation = Presentation {
    kind: "Video".into(),
    media: Some(Media {
        duration: poster.duration,
        width: poster.width,
        height: poster.height,
        audio: poster.audio,
    }),
    raster: Some(Raster {
        width: poster.pixels.width(), height: poster.pixels.height(), page: 0,
    }),
    keys: vec!["space".into(), "left".into(), "right".into()],
    ..Default::default()
};
// The attachment is pixels, not an encoded movie.

Input: request a host action

let action = match key.as_str() {
    "space" | "play_pause" => Some(MediaAction::PlayPause),
    "left" | "seek_backward" => Some(MediaAction::SeekBackward),
    "right" | "seek_forward" => Some(MediaAction::SeekForward),
    _ => None,
};
let mut reply = presentation.clone();
reply.actions = action.into_iter().collect();
// Return (reply, pixels.clone()); do not replay old actions on later replies.

FOLD consumes typed actions and acknowledges them. KIT owns decoding, host/local audio and original-media SSH range transport. AMP owns the buttons and their hit regions, receiving a palette and current playback state through the transport helper. FOLD places the timeline, playback details and AMP's returned control surface inside Preview.

Configuration

[preview.extensions.overrides]
"video/*" = "video"

This directs video MIME-family matches to the bundled provider. No configured provider is needed for ordinary recognized video files. Movie playback requires the graphical media capability; cell clients can display the poster. Version 1 does not accept URL/live-stream sources.
